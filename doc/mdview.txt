1. はじめに					*mdview-intro*

mdview は、Markdown を読むためのビューアを Vim の中に開きます。ビューアでは
次の部分を画像（またはテキスト）にして表示します。

  - ```mermaid のコードブロック（dam で描きます）
  - ディスプレイ数式: $$…$$、\[…\]、```math（dal で描きます）
  - 画像: ![alt](path)、![alt][ref]、リンク付きの画像、HTML の <img>
    （width 属性があればその幅まで）
    （PNG・JPEG・GIF・WebP・BMP、SVG は rsvg-convert があれば本来の大きさで）
  - インライン数式 $…$: x² のような 1 行のテキストに置き換えます
  - 見出し: 太字にします
  - 表: 罫線で囲み、列を揃えたテキストにします（|mdview-tables|）
  - コードブロック: 枠で囲み、言語名を出し、言語の構文の色を付けます
    （|mdview-code|）
  - 水平線（---・***・___）: ビューアの幅の線にします
  - 段落とリストの項目の文: 書式の記号を消してハイライトで表し、行をつなげ
    てビューアの幅で折り返します（|mdview-paragraphs|）
  - 引用: > を縦線にします。GitHub のアラート（> [!NOTE] など）は種類ごとの
    色と見出しで表します（|mdview-quotes|）

引用やリストの中のブロックも、その字下げの位置に描きます。文の途中の画像は、
その行を残して下に描きます。表のセルの画像は、そのセルの中に描きます。同じ行の画像は、ビューアの幅に
収まる限り横に並べます。Markdown の解析には goldmark を使うので、コードや
HTML のコメントの中の $$ は数式として扱いません。

Markdown のファイルは、普段どおりのエディタで開きます。mdview は |:Mdview|
を実行するまで何もしません。また、編集中のバッファには手を加えません。

ビューアは読み取り専用のバッファ（mdview://ファイル名）です。ソースの各行を
写し、描いたブロックは画像の高さ分の空行に置き換えて、その上に画像を重ねます。
ソースを編集すると、入力が |g:mdview_update_delay| ミリ秒止まったところで
描き直します（|g:mdview_live|）。保存したとき（|BufWritePost|）と
|:MdviewRefresh| でも描き直します。時間のかかる図は、描き終わるまで前の画像
（初めてならソースの行と「mdview: drawing…」）を表示し、ほかのブロックを先に
表示します。描き直すときは、変わった行だけをビューアに書き込みます。

画像を表示できない端末（sixel にも kitty にも対応していない端末）や、
|+image| の無い Vim でも使えます。そのときは図・ディスプレイ数式・画像を描かず
に、ソースの行のまま表示します（表のセルの画像は [alt]）。表・見出し・
インライン数式などのテキストの表示とスクロールの追従は同じように働きます
（|g:mdview_images|）。

描画は goda.vim のプラグインとして動く Go のプログラム（|g:mdview_bin|）が行います。

表						*mdview-tables*
GFM の表は、罫線（┌─┬┐ │ ├┼┤ └┴┘）で囲んだテキストにします。列は表示上の
幅（|strdisplaywidth()|）で揃えるので、日本語のセルも揃います。区切りの行の
`:--`・`:-:`・`--:` に従って左・中央・右に寄せます。
セルの中の **太字**・*斜体*・`code`・~~取消線~~・リンク・<u>下線</u> は、記号を
消してハイライトで表します（|mdview-highlights|）。<br> はセルの中の改行に、
インライン数式は 1 行のテキストにします。
セルの中の画像は、セルの中に描きます（1 つのセルに複数あれば縦に並べます）。
幅は「ビューアの幅 ÷ 列の数」まで、高さは |g:mdview_table_image_rows| 行まで
に縮めて描きます（小さい画像はそのままの大きさです）。描き終わるまでと、
描けないときは [alt] と表示します。
表がビューアの幅に収まらないときは、一番広い列から順に縮めて、セルの中で
折り返します（空白と、日本語の文字の間で折ります。句読点や閉じ括弧は行頭に
来ないようにします）。画像のある列は、画像の幅より狭くしません。ウィンドウ
の幅が変わると組み直します。
'ambiwidth' が "double" のときは、罫線の文字が 2 桁になるため、ASCII の
罫線（+ - |）を使います。

段落						*mdview-paragraphs*
段落とリストの項目の文は、**・_・`・~~・<u> などの記号、HTML のタグ、
エスケープの \ を消して、書式をハイライト（MdviewBold など）で表します。
リンクは文字だけを表示し、URL は表示しません。画像は [alt] にします（文中の
画像は段落の下に描きます）。インライン数式は 1 行のテキストにします。
段落の中の改行はつなげ、ビューアの幅で折り返します（日本語の文字どうしの
間には空白を入れません。折り返しの禁則は表と同じです）。行末の空白 2 つ・
行末の \・<br> は改行にします。リストの印と引用の縦線は最初の行に付け、
続きの行は同じ字下げにします。ウィンドウの幅が変わると組み直します。
ソースの各行は、その行の最初の文字があるビューアの行に対応させて追従します。
見出しの中の書式は、今までどおり markdown の構文の色で表します。
段落の途中の行が画像だけのとき（その行を画像に置き換えます）は、その段落
を行ごとにそのまま表示します。

コードブロック					*mdview-code*
``` と ~~~ のコードブロックを枠で囲みます。開きのフェンスの行は言語名の
入った上の線に、閉じのフェンスの行は下の線にします。中身の行の左には縦線を
付けます。上下の線の右端には角を付けます（中身の行の右には縦線を付け
ません。ウィンドウより長い行があるためです）。 >
	╭─ go ─────────────────╮
	│ func main() {
	│ }
	╰──────────────────────╯
<
中身には、Vim の構文ファイル（syntax/{言語}.vim）がある言語なら、その色を
自動で付けます（js・py・sh・c++ のような別名も読み替えます。
|g:mdview_fenced_languages|）。構文ファイルの無い言語と言語名の無いものは
MdviewCodeBlock の色にします。縦線はバッファの文字ではなく仮想テキスト
（|textprop|）なので、言語の構文は中身だけを見ます（diff の行頭の + など）。
タブは空白に展開します。閉じていないコードブロックには下の線を付けません。
mermaid と数式のフェンスも、描かないとき（|g:mdview_images|）や描けない
ときは、この枠で表示します。'ambiwidth' が "double" のときは、ASCII の
枠（+ - |）を使います。

引用						*mdview-quotes*
引用の > を縦線（│）にします。入れ子の引用は │ │ になります。ふつうの引用は
本文を薄い色（MdviewQuote）にします。引用の中の画像・図・表の横にも縦線を
続けます。> の無い続きの行（lazy continuation）には縦線を付けません。
GitHub のアラートは、引用の 1 行目が [!NOTE]・[!TIP]・[!IMPORTANT]・
[!WARNING]・[!CAUTION] だけのものです。その行を見出し（「📝 Note」など、
|g:mdview_alert_titles|）にし、縦線と見出しを種類ごとの色
（MdviewAlertNote など）にします。アラートの本文は薄くしません。
'ambiwidth' が "double" のときは、縦線に | を使います。

==============================================================================
2. 必要なもの					*mdview-requirements*

  - Vim 9.2 以降。|+textprop|
  - 図・数式・画像を描くには、さらに次のものが要ります。無いときは
    テキストだけで表示します（|g:mdview_images|）。
    - |+image| |+image_popup| |+popupwin|
    - 画像を表示できる端末（sixel または kitty）。|'imageprotocol'| と
      |v:imagebackend| を確認してください。
  - goda.vim (https://github.com/Shougo/goda.vim)
  - ビルドに Go 1.26 以降（実行には不要）

==============================================================================
3. 導入						*mdview-install*

mdview と goda.vim の 2 つを Vim のプラグインとして入れます。mermaid と数式
を描く dal と dam は、ビルドのときに Go が取ってきます。Vim のパッケージで
入れる例: >

	mkdir -p ~/.vim/pack/plugins/start
	cd ~/.vim/pack/plugins/start
	git clone https://github.com/lea-151107/mdview
	git clone https://github.com/Shougo/goda.vim
<
Vim を起動して |:MdviewBuild| を実行し、Go のプログラムをビルドします。
プラグインマネージャーで入れるときは、入れたあと・更新したあとに
goda_mdview#build() を呼ぶように設定します。 >

	" vim-plug
	Plug 'lea-151107/mdview', { 'do': { -> goda_mdview#build() } }
<	# goda-pm.vim・dpp.vim の TOML >
	hook_post_update = 'call goda_mdview#build()'
<
mdview や goda.vim を更新したときも、ビルドし直します。

キーに割り当てる例: >

	autocmd FileType markdown nnoremap <buffer> <Leader>p <Cmd>Mdview<CR>
<
==============================================================================
4. 使い方					*mdview-usage*

Markdown を開いて |:Mdview| を実行すると、右にビューアが開きます。カーソルは
ソースに残るので、そのまま編集を続けられます。ソースでカーソルを動かすと、
同じ箇所がソースと同じ高さに来るように、ビューアがスクロールします。カーソル
を動かさずにソースだけをスクロールしたとき（zt・<C-e>・マウスのホイールなど）
も同じです。
カーソル行の画像がその高さからはみ出すときは、画像全体が見えるまで（画像が
ウィンドウより高いときは、画像の上端が上に来るまで）ビューアを送ります。
ソースが最後の行まで見えているときは、ビューアも最後の行まで見せます。

`:Mdview here` では、今のウィンドウがビューアに切り替わります。もう一度
|:Mdview| を実行すると、ソースに戻ります。そのときカーソルは、ビューアで
見ていた箇所に置かれます。保存していない変更があっても切り替えられます。

ビューアで `q` を押しても閉じます。ビューアで <CR> を押すと、カーソル行に
当たるソースの行へ移ります（here で開いたときはソースに戻ります）。

画像を描けなかったブロックは、文字（罫線）で表示します。それもできないときは、
ソースの行をそのまま残し、その下にエラーを表示します。Go 側のログは
|:MdviewLog| で見られます。

==============================================================================
5. コマンド					*mdview-commands*

:Mdview [right|here]				*:Mdview*
	今のバッファのビューアを開きます。right は右のウィンドウに、here は
	今のウィンドウに開きます。引数を省いたときは |g:mdview_open| です。
	ビューアが開いているとき（またはビューアの中で実行したとき）は
	閉じます。

:MdviewRefresh					*:MdviewRefresh*
	保存せずに描き直します。ソースでもビューアでも使えます。

:MdviewBuild					*:MdviewBuild*
	Go のプログラムを |g:mdview_bin| にビルドします。goda.vim の
	goda#build() を使うので、ビルドが終わるまで Vim は待ちます。
	goda-pm.vim を使っているときは、入れた goda.vim の Go 側でビルドし、
	バイナリの隣に go.work を作ります（|g:goda#workspace|）。動いている
	バイナリは止め、次の描画で新しいものを起動します。ビルドが失敗した
	ときは、古いバイナリをそのまま使います。
	関数では goda_mdview#build() です（goda.vim の名前の決まりに合わせた
	もので、プラグインマネージャーのフックから呼べます）。バイナリと
	Vim script の版が合わないとき、goda.vim はこれを呼ぶように表示します。

:MdviewLog					*:MdviewLog*
	Go 側のログ（goda#log('mdview')）を表示します。

:MdviewClearCache				*:MdviewClearCache*
	画像のキャッシュ（|g:mdview_cache_dir|）を消します。

6. 設定						*mdview-options*

*g:mdview_open*			(既定: 'right')
	|:Mdview| を引数なしで実行したときの開き方。'right' か 'here'。

*g:mdview_live*			(既定: 1)
	1 のとき、編集中にも描き直します。0 にすると、保存したときと
	|:MdviewRefresh| だけで描き直します。

*g:mdview_update_delay*		(既定: 500)
	編集中に描き直すまでに、入力が止まっているのを待つ時間（ミリ秒）。
	挿入モードを <Esc> で抜けたあと、次のキーを押すまで描き直されない
	ときは、'ttimeout' を設定してください（vimrc があると defaults.vim
	は読まれず、<Esc> の後に続くキーを待つ間はタイマーが動きません）。 >
		set ttimeout ttimeoutlen=100
<

*g:mdview_inline_math*		(既定: 1)
	1 のとき、インライン数式 $…$ を x² のような 1 行のテキストに
	置き換えます。

*g:mdview_remote*		(既定: 0)
	1 のとき、http(s) の画像を取得して描きます（1 枚 10 秒・20MB まで）。
	0 のときは描かずにソースの行のままにします。

*g:mdview_images*		(既定: -1)
	図（mermaid）・ディスプレイ数式・画像を描くかどうか。描かないとき
	は、ソースの行のまま表示します。表のセルの画像は [alt] と表示し
	ます。インライン数式は |g:mdview_inline_math| で決まります。
	  -1	端末が画像に対応しているときだけ（|v:imagebackend| が
		"none" でないとき）
	   1	いつも（Vim が |+image| |+image_popup| |+popupwin| を持つとき）
	   0	描かない
	変えたあとは |:MdviewRefresh| で描き直します。|'imageprotocol'| を
	変えたときは自動で描き直します。

*g:mdview_table_image_rows*	(既定: 8)
	表のセルの中の画像の高さの上限（行数）。これより高い画像は縮めて
	描きます（|mdview-tables|）。

*g:mdview_alert_titles*		(既定: {})
	GitHub のアラートの見出し（|mdview-quotes|）。種類（note・tip・
	important・warning・caution）から見出しへの辞書で、無い種類は既定の
	見出しを使います。記号の幅が端末によって違うときなどに使います。 >
		let g:mdview_alert_titles = #{note: 'Note', warning: '! Warning'}
<	既定の見出しは「📝 Note」「💡 Tip」「❗ Important」「⚡ Warning」
	「⛔ Caution」です。どれも端末で 2 桁の絵文字です。

*g:mdview_fenced_languages*	(既定: [])
	コードブロックの言語名から Vim の構文への読み替え（|mdview-code|）。
	書き方は |g:markdown_fenced_languages| と同じで、"言語名=構文" と
	書きます（例: ['bash=sh', 'conf=dosini']）。|g:markdown_fenced_languages|
	の読み替えも使います。よく使う別名（js・ts・py・rb・sh・bash・yml・
	rs・c++・golang など）は設定しなくても読み替えます。

*g:mdview_sync_back*		(既定: 0)
	1 のとき、ビューアをスクロールすると、ソースも同じ箇所が上端に
	来るようにスクロールします。ソースのカーソルは、画面の外に出る
	ときだけ動かします。ビューアのウィンドウにいる間は、ソースを
	スクロールしてもビューアは追従しません（両方が互いを動かさない
	ように）。

*g:mdview_clear_redraw*		(既定: -1)
	画像が動いたとき（ビューアのスクロール、画像の位置が変わる描き
	直し）に、画面を消して描き直すかどうか（|:redraw!|）。sixel の端末
	（Windows Terminal など）は前の位置の画像を残し、新しい位置の画像が
	popup の背景で隠れることがあるので、それを防ぎます。
	  -1	|v:imagebackend| が sixel のときだけ
	   1	いつも
	   0	しない
	画像が見えていないとき、画像の位置が変わらない描き直しのときは
	行いません。

*g:mdview_bin*			(既定: $XDG_CACHE_HOME/vim/mdview/mdview か
				 ~/.cache/vim/mdview/mdview)
	Go のバイナリのパス。|:MdviewBuild| はここに作ります。マシンごとの
	ものなので、プラグインの中ではなくキャッシュに置きます。
	|g:mdview_cache_dir| と同じ場所にはしないでください（古い画像と一緒
	に消されます）。

*g:mdview_cache_dir*		(既定: $XDG_CACHE_HOME/mdview か ~/.cache/mdview)
	描いた画像（raw RGB）を置くディレクトリ。

*g:mdview_cache_days*		(既定: 30)
	この日数使っていないキャッシュは、起動後の最初の描画で消します。

*g:mdview_max_width*		(既定: 0)
	画像の幅の上限（セル数）。0 はビューアのウィンドウの幅です。

*g:mdview_max_height*		(既定: 0)
	画像の高さの上限（セル数）。0 はビューアのウィンドウの高さ - 2 です。

*g:mdview_math_size*		(既定: 0)
	数式の文字の大きさ（px）。0 はセルの高さ × 1.1 です。

*g:mdview_mermaid_scale*	(既定: 0)
	mermaid の拡大率（dam の Scale）。0 はセルの高さから決めます。

*g:mdview_font*			(既定: '')
*g:mdview_font_index*		(既定: 0)
*g:mdview_font_bold*		(既定: '')
*g:mdview_font_bold_index*	(既定: 0)
	内蔵フォントに無い文字（日本語など）に使うフォントのファイル
	（.ttf .otf .ttc）と、.ttc の中の番号。空のときは fc-match で
	日本語のゴシック体を探します。mermaid は内蔵フォントで描けない
	ときだけこのフォントで描き直します。数式は \text{} などの中の、
	数式フォントに無い文字だけに使います。

*g:mdview_cell_pixels*		(既定: [])
	端末のセルの大きさ [幅, 高さ]（px）。空のときは |getcellpixels()|
	を使い、それも取れなければ [8, 16] です。

*g:mdview_bg*			(既定: [])
*g:mdview_fg*			(既定: [])
	背景色と文字色 [r, g, b]。空のときは Normal の色（GUI か
	'termguicolors' なら GUI の色、それ以外は cterm の色番号）、端末に
	問い合わせた色（|getbgcolor()|、|v:termrfgresp|）、'background' の
	順に決めます。端末の応答が起動より後に届いたときは描き直します
	（|TermResponseAll|）。画像の透明な部分はこの背景色で塗ります。
	端末の背景色が取れずに画像の背景がずれるときは、ここで指定して
	ください。

==============================================================================
7. ハイライト					*mdview-highlights*

MdviewHeading	ビューアの見出しの行（既定: 太字）。markdown の構文の色に
		重ねて使うので、色を付けずに属性だけを指定するのが普通です。
		例: `highlight MdviewHeading cterm=bold,underline gui=bold,underline`
MdviewText	文字での代替表示（既定: Normal）
MdviewError	エラー（既定: ErrorMsg）
MdviewPending	描き途中の表示（既定: Comment）
MdviewMath	インライン数式を置き換えたテキスト（既定: Special）
MdviewTable	表の行（既定: Normal）。markdown の構文の色は使いません
MdviewTableBorder	表の罫線（既定: Comment）
MdviewTableHeader	表の見出しの行（既定: 太字）
MdviewBold	表のセルと段落の太字（既定: 太字）
MdviewItalic	表のセルと段落の斜体（既定: 斜体）
MdviewCode	表のセルと段落のコード（既定: String）
MdviewStrike	表のセルと段落の取消線（既定: 取消線）

8. 制限						*mdview-limitations*

  - インライン数式は画像ではなくテキストにします。分数などは (a + b)/c の
    ような 1 行の書き方になります。閉じの $ のすぐ後に英数字が続くもの
    （$HOME/bin:$PATH など）は数式とみなしません。
  - \[ は段落の途中では数式を始めません。$$ と \[ のブロックは、空行の
    前に閉じがあるときだけ数式にします。
  - http(s) の画像は 1 日 1 回取得し直します。
  - 字下げ（4 桁）のコードブロックは枠で囲まず、ソースのまま表示します。
  - コードブロックの中の長い行を折り返したとき、続きの行には縦線が付き
    ません。
  - 表のセルと段落の中の書式は、markdown の構文の色ではなく、
    |mdview-highlights| の Mdview* で表します。リンクは文字だけを表示し、
    URL は表示しません。
  - http(s) の画像は |g:mdview_remote| を 1 にしたときだけ描きます。
  - 画像はビューアのウィンドウの幅（と高さ）に合わせて描きます。大きさが
    変わったときは描き直します。
  - ビューアの内容は、最後に描いたときのソースです。|g:mdview_live| が 0
    のときは、保存するか |:MdviewRefresh| を実行するまで編集は反映
    されません。
  - 編集中は、入力が止まるたびにバッファ全体を Go 側へ送ります。約 5000 行
    で、要求してから表示されるまで 0.14 秒ほどです。
  - Go 側からの結果は、キャッシュのディレクトリのファイル経由で受け取り
    ます（Vim 9.2.1178 は、チャネルの call の大きな引数を解放しないため）。
  - 画像の下の端がウィンドウの上に、または上の端がウィンドウの下に
    はみ出すときは、画像の一部だけを表示します。画像がウィンドウより
    高く、上下の両方がはみ出すときは表示しません。
